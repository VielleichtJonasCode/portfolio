Ziel

Satellite Tools — Ein Python-Toolkit für orbitale Mechanik und Raketen-Startsimulation.

Ziel war ein Werkzeug, mit dem sich Mission-Design (welche Rakete für welchen

Orbit, wie viel Δv wird gebraucht?), Startkosten-Abschätzung und Lehre/Prototyping

schnell durchrechnen lassen — ohne den Overhead von Profi-Tools wie STK/GMAT.

Ablauf

Saubere Trennung in vier Module unter physics/:

  • constants.py — physikalische Konstanten (GM der Erde, g0)
  • satelite_tools.py — Orbitmechanik (Hohmann-Transfer, Vis-Viva, Orbitparameter)
  • rockets.py — Datenbank realer Raketen-Oberstufen
  • propulsion.py — Start-Simulation (Tsiolkovsky-Gleichung + Hohmann + Kosten)

  • Vis-Viva-Gleichung für elliptische Transfers implementiert
  • Spezifische Orbitalenergie zur Unterscheidung von Flucht- vs. gebundenen Orbits
  • NumPy für numerische Stabilität
  • Modular erweiterbar — neue Raketen einfach per Dictionary hinzufügen

from physics.satelite_tools import *
from physics.propulsion import start_rocket

# Hohmann Transfer LEO → GEO
transfer = hohmann_transfer(6771, 42164)  # Radien in km
# {'delta_v_total': 3894.2, 'transfer_time_hours': 5.26, ...}

# Raketen-Start simulation
result = start_rocket("falcon_9", payload=500, start_pos=6771, target_orbit=42164, m_prop_initial=107500)
# {'propellant_used': 1823.4, 'price': 6382000, 'total_Dv': 3894200, ...}

Ergebnis

Berechnet Hohmann-Transfers zwischen zwei Kreisbahnen, inklusive:

  • Δv für beide Brennmanöver (Perigäum & Apogäum)
  • Gesamtes Δv und Transferzeit
  • Neue Orbitparameter nach beliebigem Geschwindigkeitsimpuls

Simuliert Raketenstarts mit 7 reellen Oberstufen (Falcon 9, Ariane 5/6, Saturn V,

Atlas V, Soyuz, Electron), inklusive Treibstoffverbrauch, Startkosten und

Payload-Kapazität für jede Raketen/Orbit-Kombination.


Beispiel: Falcon 9, 500 kg Payload, LEO (400 km) → GEO (35.786 km)

→ Δv total: ~3.9 km/s | Treibstoff: ~1.8 t | Kosten: ~$6.3M (nur Oberstufen-Treibstoff)

Roadmap

  • Bi-elliptische Transfers für hohe Δv-Ersparnis
  • Plane-Change-Manöver (Inklination)
  • Lambert-Problem für beliebige Transferzeiten
  • Mehrkörper-Probleme (Patch Conics, Lagrange-Punkte)
  • Web-Interface mit interaktiver Orbit-Visualisierung (Canvas/WebGL)

Goal

Satellite Tools — A Python toolkit for orbital mechanics and rocket launch simulation.

The aim was to create a tool with which mission design (which rocket for which

Orbit, how much Δv is needed?), start-up cost estimation and teaching/prototyping

quickly — without the overhead of professional tools such as STK/GMAT.

Process

Clean separation into four modules under physics/:

  • constants.py — physical constants (GM of the earth, g0)
  • satelite_tools.py — Orbit mechanics (Hohmann transfer, Vis-Viva, orbit parameters)
  • rockets.py - database of real rocket upper stages
  • propulsion.py — start simulation (Tsiolkovsky equation + Hohmann + cost)

  • Vis-Viva equation implemented for elliptic transfers
  • Specific orbital energy to distinguish escape vs. bound orbits
  • NumPy for numerical stability
  • Modularly expandable — simply add new rockets via dictionary

from physics.propulsion import start_rocket

Results

Calculates Hohmann transfers between two circular paths, including:

  • Δv for both burning manoeuvres (perigee & apogee)
  • Total Δv and transfer time
  • New orbit parameters after any speed pulse

Simulates rocket launches with 7 real upper stages (Falcon 9, Ariane 5/6, Saturn V,

Atlas V, Soyuz, Electron), including fuel consumption, start-up costs and

Payload capacity for each rocket/orbit combination.


Example: Falcon 9, 500 kg payload, LEO (400 km) → GEO (35,786 km)

→ Δv total: ~3.9 km/s | Fuel: ~1.8 t | Cost: ~$6.3m (upper stage fuel only)

Road Map

  • Bi-elliptic transfers for high Δv savings
  • Plane change manoeuvre (inclination)
  • Lambert problem for any transfer times
  • Multibody problems (patch conics, Lagrange points)
  • Web interface with interactive orbit visualization (Canvas/WebGL)

Objetivo

Satellite Tools: un kit de herramientas de Python para mecánica orbital y simulación de lanzamiento de cohetes.

El objetivo era una herramienta con la que el diseño de la misión (qué cohete para qué

Órbita, ¿cuánto Δv se necesita?), estimación de costes iniciales y enseñanza/creación de prototipos

calcular rápidamente, sin la sobrecarga de herramientas profesionales como STK/GMAT.

Proceso

Separación limpia en cuatro módulos en physics/:

  • constants.py — constantes físicas (GM de la Tierra, g0)
  • satelite_tools.py — Mecánica orbital (transferencia de Hohmann, Vis-Viva, parámetros orbitales)
  • rockets.py - Base de datos de etapas superiores de cohetes reales
  • propulsion.py — Simulación de inicio (ecuación de Tsiolkovsky + Hohmann + costos)

  • Ecuación Vis-Viva implementada para transferencias elípticas
  • Energía orbital específica para distinguir entre órbitas de fuga y órbitas enlazadas
  • NumPy para la estabilidad numérica
  • Modularmente ampliable — añadir nuevos cohetes fácilmente a través del diccionario
